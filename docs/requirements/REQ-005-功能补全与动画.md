# REQ-005 功能补全与观感提升

- 状态：进行中
- 日期：2026-10-21
- 版本：从 0.18.0 起

## 1. 要做什么

把这个启动器从「能启动游戏的半成品」补成「日常真能用的启动器」，并把界面从「一堆整齐但没生气的卡片」
变成「有反馈、有动效、看得出主次」的界面。

用户原话：「你自己想办法把启动器完善完，该有的功能要有，扩展功能也要，并且 UI 要好看，
还要很明显的动画，并且要支持正版登录」。

拆成四块：

1. **正版登录**：微软账号 device code 登录，拿到 Minecraft access token，
   启动时传 `--accessToken/--uuid/--username`，并显示皮肤头像与正版名。
2. **常规功能补齐**：窗口大小与全屏、存档备份/恢复/删除、手动指定 Java、整合包安装。
3. **动画**：页面切换、列表逐条入场、进度条平滑、按钮/卡片按压反馈、登录流程的状态动画。
4. **观感**：主次分明、留白有节奏、深浅色都成立。

## 2. 不做什么

- 不做 Yggdrasil 外置登录（第三方登录服务器）——需要另一套协议与用户自填地址，本期不做
- 不做皮肤上传/换肤（只显示官方皮肤头像）
- 不做 CurseForge 整合包（需要 API key，且许可受限），只做 Modrinth `.mrpack`
- 不做自动更新启动器本体、不做多语言
- 不改 `.minecraft` 之外的磁盘位置（沿用 `DLP_HOME`）

## 5. 已知约束

- **微软登录**需要 Azure 公共客户端 id。默认内置一个公开的第三方启动器 client id，
  设置页允许用户换成自己注册的（`settings.json` 的 `msa_client_id`）。
  device code 流程不需要 client secret，属于公共客户端，符合微软对第三方启动器的允许范围。
- 微软接口在国内可直连（`login.microsoftonline.com` / `xsts.auth.xboxlive.com`），
  但 `api.minecraftservices.com` 偶尔被墙；失败要给出可读错误而不是一直转圈。
- 现有 `VersionSettings` 只有 memory/java/isolate/jvm/game args，窗口设置要新增字段并落 `options.txt`。
- `.mrpack` 的 `mods/*.jar` 在 zip 里，需要按 index.json 的 `files[].path` 映射；
  `overrides/` 目录要原样铺到版本目录。
