# REQ-002 版本管理、分片下载与模组加载器

状态：进行中（2026-10-20）
关联：REQ-001（启动器骨架）

## 1. 要做什么

用户原话拆成四件事：

1. **每个版本有单独的设置** —— 不同版本要吃不同内存、用不同 Java，隔离开关也可能不一样，
   不能全局一份配置。
2. **直接扫描 `.minecraft` 文件夹下的游戏** —— 不是只认自己下载的清单版本；别的启动器装进来的、
   手动解压的，只要在 `versions/` 下有 json 就应该出现在列表里。**一个都没有时要明确说明**，
   而不是给一个空列表。
3. **下载改成多线程** —— 单文件分片多连接（Range）+ 多文件并发。
4. **装原版时能顺手加装模组加载器和高清修复** —— Fabric / Quilt / Forge / NeoForge 全要，
   OptiFine 也要，且用自动下载 + 静默安装。

## 2. 不做什么

- 不做整合包（CurseForge / Modrinth）安装
- 不做模组管理（启用禁用、依赖解析）
- 不做 Forge 1.12 及更早版本的兼容特判（能装则装，装不上报错说明）
- 不自动下载 Java 运行时（沿用本机已装的 Java）
- 不处理 OptiFine 的授权问题：只从 BMCLAPI 镜像取，不打包分发

## 3. 验收标准

| # | 标准 | 怎么验 |
|---|------|--------|
| 1 | `versions/` 下放着 JSON 但清单里没有的版本能出现在列表并标「本地」 | 手造一个 `versions/x-test/x-test.json`，启动器里能看到 |
| 2 | `versions/` 为空时界面明确提示「没有扫描到游戏」并给出去下载页的入口 | 空目录启动，看界面文案 |
| 3 | 每个版本单独存内存/Java/隔离/额外 JVM 参数，切换版本后设置跟着切换 | 给 A 存 4G、B 存 2G，来回切 |
| 4 | 启动时用的是该版本自己的设置 | 启动 A，看进程命令行里的 `-Xmx` |
| 5 | 下载大文件时出现多个连接（分片） | 抓日志/任务数，或看服务端并发；文件 SHA1 校验通过 |
| 6 | 镜像不支持 Range 时自动退回单连接且下载成功 | 断点/日志里能看到回退记录 |
| 7 | Fabric / Quilt 装完生成 `versions/<id>` 且能启动 | 实测各装一个并启动到主菜单 |
| 8 | Forge / NeoForge 装完生成对应版本且能启动 | 实测安装器跑完、版本可启动 |
| 9 | OptiFine 能自动下载并装成独立版本 | 实测 1.20.1 装 OptiFine 后启动 |

## 4. 已知约束

- BMCLAPI 提供 Forge / NeoForge / OptiFine 的镜像下载（`bmclapi2.bangbang93.com`）
- Fabric / Quilt 有官方 meta 的 profile JSON，不需要跑安装器
- Forge / NeoForge 的安装器需要 Java，且会自己联网下载依赖
- OptiFine 安装器是 Swing GUI，无 `--headless`；改从 jar 内取出 `version.json` 与内嵌库

## 5. 方案（要点）

- `minecraft::scan`：遍历 `versions/*/`，读 `<id>.json` 的 `type`/`releaseTime`/`inheritsFrom`
- `settings`：`<root>/dlp/version-settings.json`，key = 版本 id，`"*"` 为全局默认，读时全局打底、版本覆盖
- `net::download`：>4MB 且服务端支持 Range 时切 4 片并发写同一文件，否则单连接
- `loader`：Fabric/Quilt 走 meta profile JSON → 直接落版本 JSON 再复用现有安装逻辑；
  Forge/NeoForge 跑官方 installer `--installClient`；OptiFine 解包 jar 取 `version.json` + 内嵌库

## 6. 实施记录

| 项 | 结论 | 证据 |
|----|------|------|
| 本地扫描 | ✅ | `minecraft::scan` 遍历 `versions/*/`；单测 `scan_finds_json_versions_and_skips_empty_dirs` 通过 |

| 分片下载 | ✅ | 安装 1.20.1 时日志出现 `[download] 分片 4 连接 · 18131788 字节 · .../assets/62/62…`，SHA1 校验全过 |
| Fabric | ✅ | 生成 `fabric-loader-0.19.5-26.3` |

### 踩到的坑（都写进代码注释了）

1. OptiFine 安装器只认 `%APPDATA%\.minecraft`，`-Duser.home` 会被忽略 → 需要重定向 `APPDATA`。
2. `optifine.Installer.main` 是 GUI 入口，装完会弹对话框，非 headless 会一直挂着 → 加 `-Djava.awt.headless=true`，并按「有没有生成版本目录」判定成功，不看退出码。
3. Forge/NeoForge 安装器要求目标目录有 `launcher_profiles.json`，否则直接报 "no Minecraft launcher profile"。
4. NeoForge 1.20.1 的产物目录叫 `1.20.1-forge-x.y.z`（legacy 命名），不能只按 "neoforge" 关键字找。
