# 微软登录客户端 ID 申请步骤（发布者一次性操作）

启动器用**设备码流**登录微软账号：用户点「添加微软账号」→ 启动器申请一个 8 位验证码 → 自动打开系统浏览器 → 验证码已在剪贴板 → 用户粘贴、点确认 → 自动换 XBL / XSTS / Minecraft 令牌。

设备码流不需要客户端密钥，但**必须有一个 Azure 公共客户端 ID**。微软不允许复用第一方应用（Azure CLI、Graph PowerShell、官方启动器）去申请 Xbox Live 权限，所以这个 ID 只能由发布者自己注册一次，然后编译进发布包（或随包放 `client_id.txt`）。下面是一次性操作流程。

---

## 一、准备：开通免费 Azure 账号（约 5 分钟）

个人微软账号默认没有租户，直接打开 entra.microsoft.com 会报「所选的用户帐户在租户“Microsoft Services”中不存在，且无法访问应用程序 c44b4083-…」。所以先开一个免费 Azure 账号（会创建默认租户）：

1. 打开 <https://azure.microsoft.com/free>
2. 点「免费开始使用」，用**个人微软账号**（outlook.com / hotmail.com / live.com）登录
3. 手机号验证；银行卡信息仅用于身份校验，选「免费套餐」，不会扣费（可以随时在「成本管理」里删掉支付方式）
4. 完成注册，进入 <https://portal.azure.com>，页面顶部能看到「默认目录」即成功

> 已经有 Azure 账号、或账号里有租户的，跳过这一步。

## 二、注册应用（约 3 分钟）

1. 打开 <https://portal.azure.com>（**不要**用 entra.microsoft.com）
2. 搜索框输入「Microsoft Entra ID」（旧名 Azure Active Directory）并进入
3. 左侧菜单 →「应用注册」→ 顶部「新注册」
4. 填写：
   - **名称**：`Dream Launchpad`（会显示在用户的授权页上，随你起）
   - **受支持的帐户类型**：选「**仅个人 Microsoft 帐户**」（第三项，不是「任何组织目录中的帐户」）
   - **重定向 URI**：平台选「公共客户端/本机 (Mobile and desktop applications)」，值填 `http://localhost`
     （设备码流其实用不到它，但填上以后如果想加「浏览器回调登录」也不用再改）
5. 点「注册」

## 三、允许公共客户端流

1. 在刚创建的应用左侧菜单点「**身份验证**」
2. 拉到最下面「高级设置」→「**允许公共客户端流**」→ 选「**是**」
3. 点顶部「保存」

> 不开这一项，设备码换令牌时会报 `AADSTS7000218`/需要客户端密钥。

## 四、复制客户端 ID

1. 左侧菜单「**概述**」
2. 复制「**应用程序(客户端) ID**」，形如 `12345678-1234-1234-1234-1234567890ab`
3. 这个 ID 就是启动器要用的 `client_id`

## 五、填进启动器

两种方式，任选：

- **临时测试**：把 ID 存成纯文本文件 `client_id.txt`，放在 `DLP.App.exe` 同目录（启动器的数据根就是 exe 目录），重启启动器后直接点「添加微软账号」即可。
- **界面填写**：点「添加微软账号」，窗口里粘贴 ID，按「保存并登录」。

确认能登录成功后，把 ID 发我写进代码里的 `MicrosoftAuthService.DefaultClientId`，重新发布后**所有用户都不用再填任何东西**（也可以随包附带 `client_id.txt`）。

## 六、验证清单

- [ ] 点「添加微软账号」后能看到 8 位验证码，浏览器自动打开 <https://www.microsoft.com/link>
- [ ] 粘贴验证码、在微软页面确认授权
- [ ] 启动器窗口显示「登录成功：<玩家名>」，左下角出现账号
- [ ] 重启启动器，账号还在（令牌已存进 `accounts.json`）

## 常见报错

| 报错 | 原因 | 处理 |
| --- | --- | --- |
| `AADSTS65005` / 第一方应用无法同意 | 用的是 Azure CLI / Graph 等第一方 ID | 换自己注册的 ID |
| `AADSTS7000218` 需要客户端密钥 | 没开「允许公共客户端流」 | 回「身份验证」改成「是」并保存 |
| `AADSTS50059` / 「Microsoft Services」租户不存在 | 个人账号没有租户 | 先按第一步开免费 Azure 账号 |
| `invalid_grant` | 账号保存的 client_id 和当前用的不一致 | 删掉 `accounts.json` 里的该账号重新登录 |
| 授权页显示的不是启动器名字 | 用的是别人的公共客户端 | 用自己注册的 ID |

## 附：这个 ID 是不是公开的

是。公共客户端（面向桌面/移动的 OAuth 客户端）本身没有密钥，ID 会随安装包分发，微软的设计允许这样。**不要**在应用里配置客户端密码/证书，设备码流也不需要。
